# IkkeMeny Core System

**A collaborative mock e-commerce platform. Features dynamic cart logic, real-time price calculation, and a toggleable light/dark theme system.**

---

## Overview
IkkeMeny is a functional e-commerce prototype developed as a team collaboration. It simulates a retail environment where users can browse a unique product catalog, manage items in a persistent shopping cart, and toggle between visual themes. The project demonstrates core frontend principles, now supercharged with a modernized build pipeline utilizing TypeScript and modular Sass.

## Core Features
* **Dynamic Shopping Cart**: Sophisticated, strictly-typed logic for adding, removing, and tracking quantities of products like "Vintage Pepsi" and "Slightly Old Apple".
* **Real-time Calculations**: Automatic updates of total item counts and total price using dedicated calculation functions.
* **Theme Management**: A complete light-to-dark mode toggle system using synchronized CSS classes and TypeScript triggers.
* **TypeScript Integration**: The entire application logic is backed by static typing (`types.d.ts`) to ensure robust code quality.
* **DRY Sass Architecture**: Highly modular, indented Sass architecture employing shared partials (`_variables.sass`, `_cart.sass`) for a clean separation of concerns.
* **Responsive Grid Layouts**: Uses CSS Grid and Flexbox to ensure the product display and sidebar cart remain accessible across different viewports.

## Installation and Technical Setup
The project uses Node.js to compile its assets. 

### Prerequisites
* A modern browser with JavaScript enabled.
* [Node.js](https://nodejs.org/) installed on your machine (preferably via `fnm` using an LTS version).

### Deployment & Build Steps
1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Compile Assets**:
   Run the following custom build scripts to compile the Sass and TypeScript source code into standard web files:
   ```bash
   npm run build:css
   npm run build:ts
   ```
3. **Host Files**:
   Upload the root directory to your web server. The `index.html` file will automatically load the compiled `/assets/js` and `/assets/css` files.

## Architecture
The application codebase is strictly separated into source and output directories:

### Source (`/assets/ts` & `/assets/sass`)
* **`ts/cart.ts`**: The primary TypeScript engine for cart operations and mathematical calculations.
* **`ts/cart-legacy.ts`**: Alternative legacy implementations.
* **`ts/theme.ts`**: Handles the visual state of the application.
* **`ts/types.d.ts`**: Global TypeScript interfaces (e.g., `Item`).
* **`sass/`**: Contains the modular Sass partials (`_variables`, `_cart`) and the main style entry points (`styles.sass`, `kstyle.sass`, `light-dark.sass`).

### Output (`/assets/js` & `/assets/css`)
* Standard `.js` and `.css` files generated by the compilers, ready to be consumed by the browser.
